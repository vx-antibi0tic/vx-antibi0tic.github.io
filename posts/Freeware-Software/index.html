MalTag

Welcome to Malware Labeling (MalTag), a tool designed for users who want to label malware with signatures for free!

So what is this tool do? This tool is cool beans for labeling malware! Lets say you got a bunch of binaries that you know is malware, or suspect is malware and want to label it appropriately but don't have the ability to get an expensive VirusTotal license, well this tool might show you how to ball out on a budget.

This will scan a file, print and rename the file with results, and do nothing. You can simply drag and drop multiple files into the program, and it will loop through each one and tell you whether it’s malicious. If a file is renamed with a signature, that means it was detected. I personally find this program convenient for my use case, and I think it makes the process much more user friendly for long term use.

Requirements:

  • Windows (yes, you read that correctly)
  • Windows Defender
  • Malware

When you run it against a files containing malware, the output result will look like this:

Trojan.Win32.Zusy.NCD.MTB-2ffec5b3db2c224294acd3da0ea7ed29af6309b1dc552a27b0e0dc1307a4d02f

And with this result, it will automatically rename the file you just dropped.

VTDL

Welcome to the VirusTotal File Downloader (VTDL)

A GUI tool designed for users who want easy access to VirusTotal functionality. VTDL focuses specifically on download capabilities.

Requirement: VTDL uses the VirusTotal API, which requires a VirusTotal API key. You can obtain a free API key by signing up with VirusTotal. However, free keys have rate limits and don't include access to premium features such as advanced searches and file downloads.

I created this tool because I found the command-line interface tedious for regular use. While there are various ways to integrate VirusTotal across different platforms, I believe a portable approach offers the best user experience.
